# DIMARIA Orçamentos · instaladores

Instalador do programa **DIMARIA Orçamentos** para Windows 10/11 (64 bits).

**Baixar a versão atual:** [DIMARIA-Orcamentos-Setup-1.0.1.exe](https://raw.githubusercontent.com/wltecnologico-rgb/dimaria-releases/main/DIMARIA-Orcamentos-Setup-1.0.1.exe)

O programa precisa de uma chave de ativação por computador. Depois de instalado, ele se atualiza sozinho.
